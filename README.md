# ONE WAY TICKET 🧟

A first-person zombie survival horror game built with **Godot 4.3 and GDScript**. Survive endless waves of zombies in a spooky graveyard, upgrade your arsenal, and see how long you can stay alive.

## Features

- First-person movement and mouse aiming
- Three weapons: Chainsaw, Pistol, and Machine Gun
- Infinite zombie waves with boss fights every five waves
- Health, armor, ammo, and grenade pickups
- Score system and saved highscores
- Dusk atmosphere with fog, gravestones, and dead trees
- Main menu, options, pause menu, and game-over screen
- Procedurally generated 3D environment and synthesized audio

## Controls

| Key | Action |
|---|---|
| WASD | Move |
| Mouse | Look around |
| Shift | Sprint |
| Space | Jump |
| Left Click | Shoot / Attack |
| 1, 2, 3 | Switch weapons |
| Mouse Wheel | Switch weapons |
| R | Reload |
| 4 | Flashbang |
| 5 | Explosive grenade |
| G | Quick flashbang |
| Esc | Pause |

## Requirements

- Godot 4.3
- Windows, Linux, or macOS

## Getting Started

1. Clone or download this repository.
2. Open Godot 4.3.
3. Import the `project.godot` file.
4. Run the project and select **Start Game**.
